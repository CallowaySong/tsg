a personal statement concerning Anthony Scott Galloway.

The author’s name is withheld for safety and privacy.
Please respect this boundary and refrain from publicly
identifying or speculating about the author.

## Updating the website

Edit `index.html` and commit your changes to `main`.
GitHub Pages will publish the update automatically.

Keep the `CNAME` file in place so the custom domain
continues to work.
